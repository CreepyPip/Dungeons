Попытка в создание рогалика на основе прошлого проекта Maze.  

Цель игры: На данный момент это просто залутать предметы.
При вылазке предметы добавляются в сумку и окончательно их можно получить только при выходе из подземелья.
Помешать этому могут только враги.
(Враги и боёвка нереализованы).
(Планирую добавить хоть какую-то цель, хотя бы торгаша).

Генерация самого подземелья и сундуков будет происходить в generate.c на языке С.  
На Swift происходит обработка событий (вывод на экран, действия игрока, связь функций).  
В inventory хранение найденных предметов у игрока в целом и в сумке при вылазке.  

Код ввода без прожатия Enter написан ИИ.
ObjC мост для связи класса на C++ и Swift написана с помощью ИИ, потому что ObjC тот ещё кал.
Пытался в нём разобраться как мог.

Работа с файлом на Swift тоже отчасти с помощью ИИ.
Почему работа с файлами на низкоуровневом C++ в разы легче и понятнее, чем на Swift?


Полноценного UI нет, всё взаимодействие происходит в консоли.
За стены отвечает символ '#', за игрока '@', за сундуки '?' и за вход и выход соответственно 'S' и 'E'.
