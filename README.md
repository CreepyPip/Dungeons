## Dungeon

Попытка в создание рогалика на основе прошлого проекта Maze.  

Генерация самого подземелья и сундуков будет происходить в generate.c на языке С.  
На Swift происходит обработка событий (вывод на экран, действия игрока, связь функций).  
В inventory хранение найденных предметов у игрока в целом и в сумке при вылазке.  

Код ввода без прожатия Enter написан ИИ.
ObjC мост для связи класса на C++ и Swift в основе написан с помощью ИИ.
Пытался в нём разобраться как мог.

Работа с файлом на Swift тоже отчасти с помощью ИИ.
Почему работа с файлами на низкоуровневом C++ в разы легче и понятнее, чем на Swift?

Полноценного UI нет, всё взаимодействие происходит в консоли.
За стены отвечает символ '#', за игрока '@', за сундуки '?', 
за врагов '&' и за вход и выход соответственно 'S' и 'E'.

Ходить можно на WASD, только на английской раскладке. 
Сбор предметов `?` на E.

---
## Цель

Игра имеет 7 этажей, каждый расширяется. Каждый следующий расширяется. 
Вы спускаетесь на этаж ниже, если добрались до выхода, в этом вам могут помешать монстры шастающие по этажу. 
Если умрете на этаже, спуск по этажам придётся начинать сначала. 
Также на этаже раскиданы сундуки, откуда вы можете найти предметы разной ценности.
При вылазке предметы добавляются в сумку и окончательно их можно получить только при выходе из подземелья.
Помешать этому могут только враги.
Полученные предметы можно продать и купить за них зелья, для облегчения прохождения этажа.

В конце 7 этажа вас будет ожидать босс. Подготовьтесь к нему заранее.

Есть "Бесконечный режим" для накопления рекорда по этажам и счету(по предметам). 
Будет запись рекорда в файл.
